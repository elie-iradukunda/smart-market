# Quick Start Guide - Simplified Platform

## 🎯 For STAFF WORKERS

### Your New Dashboard
When you log in, you'll see a **green "My Tasks" button** - this is your command center!

### How to Use "My Tasks"
1. **Click "My Tasks"** from the sidebar or dashboard
2. **See all your assigned work** in one place
3. **Filter by priority**:
   - 🔴 **OVERDUE** - Handle these first!
   - 🟠 **DUE TODAY** - Complete today
   - 🟡 **URGENT** - Due in 2 days
   - ⚪ **Active Tasks** - All pending work

### Complete a Task
1. Click **"View Details"** on any task
2. See client requirements and deadline
3. Complete the design work
4. Click **"Upload Work"** to submit
5. Task moves to "Completed" ✅

### Your Simplified Menu
```
📊 Dashboard       - Overview of your work
✅ My Tasks        - YOUR PRIORITY VIEW
📦 Orders          - All orders (if you need context)
🏭 Production      - Work orders and schedule

## 👔 For ADMIN

### Assign Orders to Workers (NEW!)
1. Go to **Orders** (now at top of menu)
2. Click any order to view details
3. Click **"Assign Worker"** button
4. Select a staff member from the list
5. Done! Worker sees it immediately in "My Tasks"

### Your Simplified Menu
```
📊 Dashboard       - Business overview
📋 Orders          - ALL ORDERS (top priority)
👥 Users           - Manage team & permissions

🤝 CRM             - Leads, customers, quotes
🏭 Operations      - Production, supplies, POS
📢 Marketing       - Campaigns & ads (KEPT!)
⚙️ Settings        - System configuration

## 🔄 Complete Workflow Example

### Scenario: Client Orders a Logo Design

**1. CLIENT** (Online or Walk-in)
- Submits order: "Need a modern logo for my coffee shop"
- Uploads reference images
- Order #1234 created

**2. ADMIN/SALES** (Receives Order)
- Sees Order #1234 in dashboard
- Reviews requirements
- Clicks **"Assign Worker"**
- Selects "John (Designer)"
- Order status → "In Progress"

**3. STAFF (John)**
- Logs in → Sees **"My Tasks"** badge (1 new task)
- Clicks "My Tasks"
- Sees: **Order #1234** - Logo Design - **DUE TODAY**
- Clicks "View Details"
- Completes the logo design
- Clicks "Upload Work"
- Uploads final files (PNG, SVG, AI)

**4. CLIENT** (Gets Notified)
- Receives email: "Your design is ready!"
- Logs in → Goes to "Files"
- Downloads all logo files
- Leaves feedback (optional)

**Total Time**: Order to delivery in 1 day ✅

## 🆘 Quick Troubleshooting

### "I don't see my tasks"
- Make sure you're assigned to orders (ask admin)
- Check if you're logged in as Staff role
- Refresh the page

### "Can't assign worker"
- Make sure the user has Staff role (role_id: 3)
- Check if you have admin permissions
- Verify the order exists

### "Marketing module missing"
- It's now under a submenu!
- Admin: Operations → Marketing
- Sales: Marketing → Campaigns/Ads
